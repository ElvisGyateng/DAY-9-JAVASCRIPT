# Day 9 - TaskFlow API Dashboard

## Overview

TaskFlow is a small task management dashboard built as part of my Day 9 frontend internship practice.

The project combines HTML, CSS, JavaScript, DOM manipulation, asynchronous JavaScript, and REST APIs.

## Features

- View tasks from a REST API
- Display total, completed, and pending tasks
- Search tasks by title
- Filter tasks by status
- Create new tasks
- Mark tasks as completed or pending
- Delete tasks
- Loading states
- Error handling
- Empty states
- Retry functionality
- Form validation
- Responsive design

## API

This project uses JSONPlaceholder as a practice REST API.

https://jsonplaceholder.typicode.com/

The following HTTP methods are used:

- GET
- POST
- PATCH
- DELETE
